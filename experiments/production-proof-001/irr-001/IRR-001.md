## 11. Findings and limitations

These do not change the REPRODUCED status but are recorded for the later phases
and for honesty about what this record does and does not establish.

- **Finding R-1 (traceability).** No git tag points at the frozen Stage 2 commit
  `7de0163`. §30 asks for "exact branch **and tag**"; only a branch exists. The
  branch is mutable, so the commit SHA is the authoritative anchor. Recommend
  cutting an immutable tag (e.g. `exp-001-stage2-frozen`) before Phase 2 so the
  freeze point cannot drift.
- **Limitation L-1 (clean machine).** Reproduction ran in an isolated working
  tree (fresh clone, separate directory) but on the **same host, OS, and Node
  install** as development. This satisfies "must not reuse the developer working
  tree" but not a genuinely independent machine. A second reproduction on
  different hardware/OS is still owed before Production Verified.
- **Scope reminder.** These 82 tests are **offline wiring/evidence units**. Per
  the Stage 2 README itself: GitHub source enforcement is not measured,
  target/base-state binding is unresolved, and F-001/F-002 remain open. A green
  suite here is necessary for the Phase 1 gate, not evidence of the core
  invariant.
